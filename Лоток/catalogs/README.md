# Каталоги кабеленесущих систем

Локальная база официальных материалов для распознавания спецификаций конкурентов и последующего подбора аналогов KLM.

## Покрытие

- Загружены официальные материалы: DKC, IEK, EKF, OSTEC, Промрукав.
- По названию и характерным артикулам также распознаются: КМ-профиль, СЗПК, OBO Bettermann, KOPOS, Niedax и Vergokan.
- Полный перечень источников, даты и типы документов находятся в `sources.json`.

Каталоги принадлежат соответствующим правообладателям и сохранены как технические источники. Перед коммерческим предложением результат автоматического сопоставления необходимо проверить по актуальной номенклатуре и параметрам покрытия, толщины металла и несущей способности.

## Архитектура подбора

1. Загруженная таблица нормализуется в позиции: наименование, артикул, количество, единица.
2. Производитель определяется по бренду, серии и шаблону артикула.
3. Из описания извлекаются тип изделия и габариты.
4. Формируется предварительный аналог KLM; неоднозначные позиции помечаются для инженерной проверки.

Следующий этап наполнения — извлечение полных товарных таблиц из PDF/XLSX в единый индекс JSON с точными артикулами KLM.
